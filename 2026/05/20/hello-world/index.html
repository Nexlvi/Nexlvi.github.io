Hexo 博客写作指南

2026年05月20日 473 字 大概 2 分钟

文章属性（front-matter）

文章顶部的 --- 块里可以写这些：

属性 说明 示例
title 文章标题 title: 我的第一篇文章
date 发布日期 date: 2026-05-20
cover 封面图（首页列表 + 文章页顶部都会显示） cover: /images/photo.jpg
tags 标签，显示在文章底部和侧边栏标签云 tags:\n - 网络\n - 安全
categories 分类 categories:\n - CTF
comments 是否开启评论，默认开 comments: false 关闭
hide_copyright 隐藏版权声明 hide_copyright: true

不设 cover 的话会自动用 _config.kira.yml 里设置的全局背景图。

插入图片

  • 图片放在 source/images/ 目录下
  • 所有图片会自动懒加载 + 点击放大灯箱
  • 如果不想启用灯箱，给 img 加 disabled-kira-image class（需要写 HTML）

插入视频

B站视频

可选参数：{% biliplayer BV号 分P 弹幕 %}，例如：

  • {% biliplayer BV1xx411c7mD 1 1 %} — 第 1 分P，开启弹幕
  • {% biliplayer BV1xx411c7mD 1 0 %} — 第 1 分P，关闭弹幕

AV 号也可以用：

  • {% biliplayer av123456 %}
