文章属性（front-matter）

文章顶部的 --- 块里可以写这些：

属性 说明 示例
title 文章标题 title: 我的第一篇文章
date 发布日期 date: 2026-05-20
cover 封面图（优先级高于全局 banner） cover: /images/photo.jpg
banner 文章页顶部大图（覆盖全局 banner） banner: /images/banner.jpg
tags 标签 tags:\n - Hexo\n - 教程
categories 分类 categories:\n - CTF
comments 是否开启评论 comments: false 关闭
toc 是否显示目录 toc: false 关闭
sidebar 是否显示侧边栏 sidebar: false 关闭
copyright 是否显示文章版权 copyright: false 关闭
sticky 置顶文章 sticky: true
mermaid 启用 Mermaid 图表 mermaid: true
outdated 过期提醒 outdated: false 关闭
excerpt 自定义摘要 excerpt: 这是摘要文字
keywords SEO 关键词 keywords: hexo, blog
description SEO 描述 description: 一篇教程

不设 cover 的话会自动用 _config.reimu.yml 里设置的全局 banner 图。

插入图片

  • 图片放在 source/images/ 目录下
  • 所有图片自动懒加载
  • Reimu 使用 Photoswipe 灯箱，点击图片可全屏浏览、缩放、滑动切换

其他

  • 字数统计 & 阅读时间：自动显示在文章 meta 栏（footer.count: true）
  • 代码高亮：基于 highlight.js
  • 数学公式：支持 KaTeX / MathJax（math.enable: true）
  • Mermaid 图表：支持（mermaid.enable: true）
  • 响应式：自适应手机 / 平板 / 桌面，支持暗色模式
  • Pace 进度条：页面加载进度条（pace.enable: true）
